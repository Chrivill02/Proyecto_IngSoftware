# 🎮 Pelusa miedosa - 2D Mobile Platformer

Un videojuego de plataformas 2D optimizado para dispositivos móviles, desarrollado en **Unity**. Este proyecto destaca por su enfoque en la arquitectura de software, aplicando **principios SOLID** en C# para garantizar un código escalable, modular y fácil de mantener en un entorno de desarrollo colaborativo.

## 🚀 Características Principales (Features)

* **Arquitectura Limpia (SOLID):** Scripts diseñados con responsabilidad única, interfaces para desacoplar sistemas (ej. sistema de daño, inputs, movimiento) y código altamente modular.
* **Integración Compleja de Escenas:** Gestión y orquestación de múltiples escenas independientes (niveles) creadas por un equipo de 6 desarrolladores, garantizando transiciones fluidas y persistencia de datos del jugador.
* **Controles Móviles Optimizados:** Implementación de *touch inputs* responsivos y UI adaptativa para pantallas de diferentes resoluciones.
* **Trabajo Colaborativo y Control de Versiones:** Gestión estricta de repositorios con Git, manejo de ramas (*branches*), resolución de conflictos en archivos `.scene` y `.prefab`, y flujos de trabajo en equipo.
